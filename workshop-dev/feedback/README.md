# feedback/

What we learned running a workshop, written so the next run starts from it rather
than rediscovering it.

One file per round. Facilitator retrospectives, participant feedback, and anything
that changes how the next version should be built. Dated, and additive — a later
round that contradicts an earlier one says so rather than replacing it, because the
disagreement is usually the useful part.

Keep it specific. "Too much theory" is only worth writing down if it comes with which
theory, where it sat in the session, and what should have been there instead.
