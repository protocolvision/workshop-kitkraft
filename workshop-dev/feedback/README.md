# feedback/

What we learned running a workshop, written so the next run starts from it rather
than rediscovering it.

Dated and additive: a later round that contradicts an earlier one says so rather than
replacing it, because the disagreement is usually the useful part. Keep it specific.
"Too much theory" is only worth writing down with which theory, where it sat, and what
should have been there instead.

**Start with `retro-guide.md`** — the method for running a retrospective from evidence
rather than memory, reused after every run.

| File | What it is |
|---|---|
| `retro-guide.md` | How to run a retrospective: principles, agenda, questions, participant questionnaire |
| `evidence.sh` | Regenerates the repo-derived scorecard, identically each run |
| `2026-09-evidence.md` | The September 2026 run's evidence pack |
| `2026-09-facilitator-retro.md` | First facilitator retrospective after the September 2026 run |
