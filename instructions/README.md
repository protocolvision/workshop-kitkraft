# Instructions — paste into your harness

Each file below is written for your harness, not for you. Open your harness at the clone root (the folder containing `AGENTS.md`), paste the whole file, and say "do this". The pins in #kitcraft point here whenever a block is too long for Discord.

`orient.md` (before S1) · `async-1.md` (after S1) · `S2-kit.md` (S2 build) · `S2-critique.md` (S2 breakout) · `async-2.md` (after S2) · `S3-bridge.md` (S3 breakout). Also: `participants/README.md` (S1 inventory block), `bridges/README.md` (stub bridges).

Paths, one place: your folder is `participants/<name>/` (inventory.md, kit/, bridges/<target>.md, LOG.md); the template is `PARTICIPANT_TEMPLATE/`; facilitator kits are `facilitator/<name>/kit/`. Every block starts with a step 0 that checks the harness is at the clone root and names your folder; you write only inside it and read anywhere.
