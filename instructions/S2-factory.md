# S2 — convert a kit into a factory (20 minutes in #kafka; paste into your harness)

Human header: a **factory** is a kit with a declared interface that a stranger's agent can use without talking to you. Tonight you take one kit you already identified — your own (the `## Kit` task in your inventory, or something under `## Built / use`) or a facilitator kit (`facilitator/rafa/kit/`, `facilitator/sachin/kit/`) — and convert it. The interface ladder: **rung 1** = README + SKILL.md a person hands to their agent + one worked example in `examples/`; rung 2 = static page; rung 3 = MCP; rung 4 = API / A2A. The deliverable is rung 1 done properly: a README whose `Interface:` line states the rung and how to call it, a SKILL.md whose description triggers correctly, `examples/input.*` + `output.*`. Rungs 2+ are optional stretch. Converting a facilitator kit means copying it into your folder, adapting it to your own organisation and data (inputs, constraints, do-nots), declaring the interface, and crediting the source on the README's first line. Private kit: content stays on your machine; the README here is a stub. Overnight, fix what your triad's agent found (`async-2.md`) and push v2.
