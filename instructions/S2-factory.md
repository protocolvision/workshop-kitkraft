# S2 — convert a kit into a factory (20 minutes in #kafka; paste into your harness)

A **factory** is a kit with a declared interface that a stranger's agent can use without talking to you. Tonight you take one kit you already identified — your own (the `## Kit` task in your inventory, or something under `## Built / use`) or a facilitator kit (`facilitator/rafa/kit/`, `facilitator/sachin/kit/`) — and convert it. Interface ladder: **rung 1** = README + SKILL.md a person hands to their agent + one worked example in `examples/`; rung 2 = static page; rung 3 = MCP; rung 4 = API / A2A. Deliverable: rung 1 done properly (README with an `Interface:` line stating the rung and how to call it, SKILL.md whose description triggers correctly, `examples/input.*` + `output.*`); rungs 2+ are optional stretch. Converting a facilitator kit means copying it into `participants/<name>/kit/`, adapting it to your own organisation and data (inputs, constraints, do-nots), declaring the interface, and crediting the source on the README's first line. Private kits: content stays on your machine; the README here is a stub. Fix what your partner's agent found overnight (`instructions/async-2.md`) and push v2.
