# S2 — convert a kit into a factory (20 minutes in #kafka; paste into your harness)

Human header: A factory is a flexible job shop: a folder hierarchy on your own machine where agent sessions work at specialised workstations and hand artifacts to each other, making varied things with a flexibly configured set of tools. A kit is one adaptation for one job; a factory is the infrastructure that runs kits and produces *intermediates* — work-in-progress and skills that another factory can consume — rather than finished artifacts. The declared interface is how a factory exposes an intermediate to a stranger's agent. Tonight you take one kit you already identified — your own (the `## Kit` task in your inventory, or something under `## Built / use`) or a facilitator kit (`facilitator/rafa/kit/`, `facilitator/sachin/kit/`) — and convert it: (1) place it in a job-shop structure — its steps as workstations, its outputs as handoff artifacts, inside `participants/<you>/kit/`; (2) name the intermediate it exports for someone else's factory; (3) declare the interface for that intermediate. The interface ladder: **rung 1** = README + SKILL.md a person hands to their agent + one worked example in `examples/`; rung 2 = static page; rung 3 = MCP; rung 4 = API / A2A. The deliverable is rung 1 done properly: a README whose `Exports:` line names the intermediate and whose `Interface:` line states the rung and how to call it, a SKILL.md whose description triggers correctly, `examples/input.*` + `output.*`. Rungs 2+ are optional stretch. Converting a facilitator kit means copying it into your folder, adapting it to your own organisation and data (inputs, constraints, do-nots), declaring the interface, and crediting the source on the README's first line. Private kit: content stays on your machine; the README here is a stub. Overnight, fix what your breakout group's agent found (`async-2.md`) and push v2.
