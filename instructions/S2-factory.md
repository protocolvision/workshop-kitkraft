# S2 — convert a kit into a factory (20 minutes in #kafka; paste into your harness)

A factory is a flexible job shop: a folder hierarchy on your own machine where agent sessions work at specialised workstations and hand artifacts to each other, making varied things with a flexibly configured set of tools. A kit is one adaptation for one job; a factory is the infrastructure that runs kits and produces *intermediates* — work-in-progress and skills that another factory can consume — rather than finished artifacts. The declared interface is how a factory exposes an intermediate to a stranger's agent. Tonight you take one kit you already identified — your own (the `## Kit` task in your inventory, or something under `## Built / use`) or a facilitator kit (`facilitator/rafa/kit/`, `facilitator/sachin/kit/`) — and convert it: (1) place it in a job-shop structure — its steps as workstations, its outputs as handoff artifacts, inside `participants/<you>/kit/`; (2) name the intermediate it exports for someone else's factory; (3) declare the interface for that intermediate. Interface ladder: **rung 1** = README + SKILL.md a person hands to their agent + one worked example in `examples/`; rung 2 = static page; rung 3 = MCP; rung 4 = API / A2A. Deliverable: rung 1 done properly (README with an `Exports:` line naming the intermediate and an `Interface:` line stating the rung and how to call it, SKILL.md whose description triggers correctly, `examples/input.*` + `output.*`); rungs 2+ are optional stretch. Converting a facilitator kit means copying it into `participants/<name>/kit/`, adapting it to your own organisation and data (inputs, constraints, do-nots), declaring the interface, and crediting the source on the README's first line. Everything in the repo is public. Keep private work in a private workspace on your machine; put in the repo only what you are comfortable sharing. Fix what your partner's agent found overnight (`instructions/async-2.md`) and push v2.
