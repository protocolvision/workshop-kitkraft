# zakhap

## Kits I use
### 1. worldview-generator
- What it is: a Node CLI plus two Claude Code skills, `worldview-ingest` and `worldview-crystallize`, run against a project directory of imported documents
- The job it does: distills transcripts and corpuses into a commonplace book and crystallizes that into a character/skill sheet
- How often I use it: weekly
- What I adapted: batches of ten files at a time, multiplexed across subagents to find interesting and useful quotes, and it runs on the Claude Code subscription instead of an API key
- Who else uses it: only me
- Where it lives: the `worldview-generator` repo on my machine, with the two skills in `~/.claude/skills/`

### 2. unslop
- What it is: a Claude Code skill, a single SKILL.md with a pattern list and an "adding soul" section
- The job it does: removes AI-isms from much of the writing I do
- How often I use it: daily
- What I adapted: nothing, I run it as-is; I picked it up from somewhere else
- Who else uses it: shared more widely
- Where it lives: `~/.claude/skills/unslop/`
