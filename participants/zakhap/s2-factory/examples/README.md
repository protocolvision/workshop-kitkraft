# Worked example — rung 1

`input.md` — the corpus the person running this brings. Five public-domain extracts,
two holders, no scrubbing needed.

`output.md` — `critic.md` as produced. Two contested terms with both positions kept
and named, one settled term, every quote verbatim with a source, every position
carrying a `refuses:` line a downstream gate can act on.

`critic.log.md` — what was dropped and why. Read this one first when judging whether
the run was honest.

To run it: hand this folder to your agent and say `run SKILL.md on examples/input.md`.
The `## allegiance` block comes back empty; you fill it.
