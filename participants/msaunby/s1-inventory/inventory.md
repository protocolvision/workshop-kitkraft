### 1. VS Code Copilot
- What it is: Copilot in VS Code; sometimes Continue with Ollama for local code completion
- The job it does: Coding assistance — mostly Python, sometimes reading/writing code in languages I don't know well (e.g. PHP)
- How often I use it: Daily
- What I adapted: Steered it to work with robot hardware, deploying to the BeagleBone device via SSH
- Who else uses it: My team — others use similar tools, mostly sharing tips
- Where it lives: ~/github/msaunby/beaglebone-robot (hobby project)

### 2. AWS Q
- What it is: AWS Q chat, used in the AWS web console
- The job it does: Describe an issue affecting a deployed site and ask for diagnostics from system logs
- How often I use it: As needed — daily at first after deployment, less frequent once the system is stable
- What I adapted: Adapted my own working style to fit better with AI — reviewing AI-generated changes carefully since they're often more than the actual scope, and starting over on a new issue branch rather than accepting oversized changes
- Who else uses it: Colleagues — encouraged them to use it too
- Where it lives: AWS web console
