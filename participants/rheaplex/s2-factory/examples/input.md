# Brief — "Tide Tables" (synthetic example)

A small web piece that shows live tide and current data for one stretch of coast. It updates
through the day. I want it to feel like something a harbour office would put on the wall, not
like a weather app.

References: Bauhaus plus railway timetable plus deep-sea bioluminescence. Not a copy of any of
them — especially no retro-poster pastiche.

Medium: a single web page, opened from a file, no server.

Constraints: no build step, no framework, no web fonts (system fonts only), and it has to stay
readable in a bright room and in a dark room.

Recurring features I keep drawing and want defined as terms: "swell" (how a rising series is
drawn) and "slack" (how a still period is drawn).

Put the spec at docs/aesthetic-spec.md.
