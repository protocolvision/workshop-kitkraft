# Build log — Sprungbrett demo

Append only. One row per change, newest at the bottom. Never edit or delete a row: if something here turns out to be wrong, add a row saying so. Rows are written by whoever makes the change, human or assistant.

Columns: **#** sequence · **date** · **asked by** · **what changed** · **why** · **supersedes**.

This file answers "how did this get built and why does it look like this" for anyone picking it up later. The spec (`spec_rafa_v2.md`) says what the thing is now; this says how it got there.
