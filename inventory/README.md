# Inventory (Session 1)

One file per participant: `inventory/<name>.md`, where `<name>` is your GitHub username, lowercase. Your harness writes it: paste Block 1 of `instructions/S1-inventory.md` (and later Block 2) and say "do this". No harness? `instructions/no-harness.md`. Rule for the exercise: read other people's inventories only through your agent, never in the browser.

## The one schema

Every inventory file has exactly these sections, in this order. The pre-work push creates the file with the headings; S1 fills them; nothing else rewrites them.

```
# <name>

## Recurring tasks
1. <task, one line>. Recurring: yes/no. Depends on something I know that a stranger would not: yes/no — <why, one line>.
2. …
3. …

## Built / use
<anything AI-native you built or use that others could use, link or name; or "none">

## Kit
<the task that becomes the kit>. Public / Private.

## Posture
<Partnership / Hypervigilance / Overreliance / Compliance, or "not taken">

## Log
<ISO timestamp> | <S1|async> | <name> | <type> | <one line>
```

Public means: task names and one-line descriptions, readable by anyone. No client names, numbers, credentials, or NDA material. `_example-rafa.md` is a filled example; files starting with `_` are not participants.
